# Solar Bright — animated solar cleaning website

Node.js + Express multi-page site for **Solar Bright**  
Tagline: *Clear the Dust. Boost the Power*

## Features

- Full-viewport cinematic media reel (videos + images)
- Active clip plays full screen, then slides to the right as the next comes forward
- Brand logo, cleaning photos, and WhatsApp demo videos
- Pages: Home, About, Services, Results, Contact

## Run

```bash
npm install
npm start
```

Open http://localhost:3000
